# AWS 421 전체 기간 수집·검증 보고서 (ASOS 108 비교)

- 실행일: 2026-11-17 / 지점: AWS 421(성동) / API: 방재기상월보 `AwsMtlyInfoService/getDailyAwsData`
- 요청 기간: 2025-01-01 ~ 2026-10-31 (669일), 월 단위 22회 호출. 인증키는 출력·저장하지 않음
- **이 데이터는 검증 중이며, 검증 완료 전에는 매출 예측 학습에 사용하지 않는다.**

## 1. 핵심 요약

1. **수집 성공은 638일(2025-01-01 ~ 2026-09-30)이다. 2026-10(31일)은 API가 `resultCode 99 "발간되지 않은 기간입니다."`를 반환해 수집하지 못했다.** 따라서 요청한 669일 전체는 확보하지 못했다.
2. 기온(평균·최고·최저) 3개 변수는 638일 모두 결측 0, min ≤ avg ≤ max 위반 0건이다.
3. **강수량은 638일 중 385일이 결측(`null` 369일, `x` 16일)이다. 2025-01~04는 결측이 없고, 2025-05부터 결측이 크게 늘었다.** 결측을 0으로 바꾸지 않았다.
4. 기온은 ASOS 108과 가깝다(MAE 평균 0.39℃, 최고 0.48℃, 최저 0.82℃). 최저기온은 AWS가 평균 +0.63℃ 높다.
5. 강수는 AWS 421을 그대로 학습 변수로 쓰기에 부적합해 보인다. 결측이 많고 결측 의미가 불명확하다. 또 AWS 421과 ASOS 108의 강수 차이가 크다.

## 4. 강수 `null`·`x`의 의미 (확인된 것과 추정)

API가 `rn_day`에 숫자 대신 `null` 또는 `x` 문자열을 반환했다. 공식 설명은 확인하지 못했다. 아래는 이 데이터에서 관찰한 사실이다.

- 순별·월 합계 행: 합계가 숫자인 61개 기간은 모두 일별 숫자 값의 합과 정확히 일치했다(불일치 0). 그중 45개는 `null` 일이 포함돼 있었다. 즉 합계는 `null` 일을 제외하거나 0으로 간주하고 계산된 것으로 보인다.
- 합계가 `null`인 기간은 23개(순 13 + 월 10)이며, 모두 `x` 일이 포함된 기간이다. `x` 일이 있는 기간의 합계는 예외 없이 `null`이었다. 따라서 **`x`는 "합계 계산 불가"를 일으키는 결측/오류 표기**로 추정된다.
- ASOS 108과 대조: AWS `null` 369일 중 ASOS 공란 294일, ASOS 0.0 52일, ASOS 양의 값 23일(대부분 0.1~1.4mm, 최대 2025-07-08의 11.8mm). `null`은 대체로 무강수일에 나타나지만 **전부 무강수라고 단정할 수 없다**.
- AWS `x` 16일 중 ASOS 양의 값 11일이다(2025-09-13 63.7mm, 2025-06-16 20.0mm, 2026-05-12 18.1mm 등). `x`는 강수가 있었을 가능성이 높은 날에도 나타난다.
- 결론: `null`을 0으로 치환하면 ASOS 기준 양의 강수 23일(`x` 제외)을 놓치므로 치환하지 않았다. 의미 확정은 기상청 확인이 필요하다.

## 7. 판단 (근거 범위 안에서)

- **기온**: AWS 421은 ASOS 108과 일 단위로 가깝고(MAE 0.4~0.8℃) 결측이 없다. 다만 편차에 계절성이 있고(특히 최저기온), 비교 대상이 가까운 다른 지점일 뿐 정답 기준은 아니다.
- **강수**: AWS 421은 2025-05부터 결측이 많고(385/638), 의미가 불명확한 `null`·`x`가 섞여 있어 현재 상태로는 학습 변수로 부적합해 보인다. 두 지점의 강수는 서로 보완할 수는 있으나 값 정의가 같다고 볼 근거가 없다.
- **미확정**: `null`의 의미(무강수 vs 미관측), `x`의 의미, ASOS 공란의 의미, 2026-10 데이터 발간 시점, 지점 421의 센서·이전 이력.

## 8. 권장 후속 조치 (미실시)

1. 기상청 또는 공공데이터포털에 `rn_day`의 `null`/`x` 정의와 2026-10 발간 일정을 문의한다.
2. 2026-10이 발간되면 해당 월만 재호출해 이 폴더에 추가 수집한다(기존 파일 덮어쓰기 없이 별도 처리).
3. 기온만 먼저 보조 변수 후보로 검토하고, 강수는 의미가 확인될 때까지 AWS 421 값을 쓰지 않는다. 결정은 사용자 판단 사항이다.

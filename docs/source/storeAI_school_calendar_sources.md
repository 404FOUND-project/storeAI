# 학교 학사일정 원자료 정리 (수정본)

작성 목적: storeAI의 2025-01-01~2026-10-31 일별 학사일정 피처 생성을 위한 Codex 입력 자료

## 1. 자료 사용 원칙

1. 한양대학교 서울캠퍼스와 한양여자대학교는 별도의 학교 데이터로 관리한다.
2. 한양대학교 및 한양여자대학교의 일반 학사일정은 사용자가 각 학교 공식 홈페이지에서 직접 복사해 제공한 자료다.
3. 일반 학사일정의 출처 상태는 `official_website`, 검증 상태는 `verified`로 기록한다.
4. 한양대학교 시험기간은 사용자가 한양대학교 재학생 지인 등을 통해 직접 확인한 정보다. 공식 홈페이지에서 확인한 일정과 구분하여 `user_confirmed`로 기록한다.
5. 한양여자대학교 시험기간은 공식 홈페이지에서 제공된 일정에 명시되어 있으므로 `verified`로 기록한다.
6. 한양대학교 서울캠퍼스와 한양여자대학교의 일정을 서로 혼합하지 않는다.
7. `(ERICA)`로 표시된 일정은 서울캠퍼스 분석에서 제외한다.
8. 중간고사·기말고사로 명시되거나 사용자가 직접 확인한 일정만 시험 기간으로 분류한다.
9. 강의평가, 성적입력·열람·정정, 수강신청 등은 시험 기간으로 분류하지 않는다.
10. 원자료에 명시되지 않은 날짜는 임의로 추정하지 않는다.
11. 원자료 CSV에는 일별 데이터 생성 범위 밖의 일정도 보존한다.
12. 일별 피처 생성 범위는 2025-01-01~2026-10-31이다.

## 4. Codex 처리 지침

1. 학교명은 `한양여자대학교`, `한양대학교 서울캠퍼스`로 통일한다.
2. 두 학교의 일정은 별도 학교 레코드로 관리한다.
3. 원자료 CSV에는 일정별 시작일, 종료일, 일정명, 일정 유형, 출처 유형, 검증 상태, 원문 출처를 보존한다.
4. 공식 홈페이지에서 복사한 일반 학사일정은 `source_type=official_website`, `verified_status=verified`로 기록한다.
5. 한양대학교 시험기간은 `source_type=user_confirmed`, `verified_status=user_confirmed`로 기록한다.
6. 한양여자대학교 시험기간은 공식 홈페이지 자료이므로 `verified`로 기록한다.
7. 중간고사·기말고사만 시험 이벤트로 분류한다.
8. 강의평가, 성적입력·열람·정정, 수강신청은 시험 이벤트로 분류하지 않는다.
9. 방학·개강·종강·계절학기·보강주간은 별도 이벤트 유형으로 유지한다.
10. 하루짜리 이벤트는 시작일과 종료일을 같은 날짜로 기록한다.
11. 날짜 범위 이벤트는 시작일부터 종료일까지 모든 날짜에 해당 이벤트가 적용되도록 한다.
12. 연도를 넘는 이벤트도 원래 날짜 범위를 보존한다.
13. 일별 피처는 2025-01-01~2026-10-31 범위만 생성한다.
14. 원자료에 없는 일정은 임의 보간하거나 추정하지 않는다.
15. `known` 계열 컬럼은 단순히 이벤트가 발생한 날짜만 1로 표시하는 방식과 구분한다. 해당 날짜의 상태를 실제로 알고 있는지와 이벤트 발생 여부를 별도로 표현한다.
16. 학기 시작일과 종료일만으로 학기 전체 기간을 임의로 확장하지 않는다. 학기 활성 여부를 만들 경우 시작일·종료일이 모두 확인된 기간에 한해 생성하고, 종료일이 없는 학기는 미확인으로 유지한다.
17. `school_event_count_complete`는 해당 학교의 모든 행사가 수집된 경우에만 완전한 값으로 취급한다.
18. 기존 프로젝트 DB, Django 모델, 마이그레이션, 매출 데이터 및 예측 모델은 수정하지 않는다.
19. 이번 작업에서는 원자료 CSV와 일별 피처 CSV만 생성 또는 갱신한다.
20. 생성 후 학교별 이벤트 수, 시험 이벤트 수, 날짜 범위, 출처 상태, 중복 이벤트, 누락 날짜를 검증하고 결과를 보고한다.

## 5. 현재 확보되지 않았거나 주의할 자료

- 한대부고 2025년 일정은 공식 자료가 아닌 추정 자료이므로 별도 `estimated` 상태를 유지한다.
- 한대부고 2026년 일정은 사용자가 공식 홈페이지에서 받은 PDF를 출처로 사용한다.
- 한양대학교 시험기간은 사용자가 직접 확인한 정보이며 공식 홈페이지 일정과 출처를 구분한다.
- 한양여자대학교 2025·2026년 전체 일정은 공식 홈페이지에서 제공된 원문을 기준으로 한다.
- 한양대학교 2025~2027년 제공 일정은 공식 홈페이지 원문을 기준으로 한다.

**중요: CSV 검증이 완료되기 전까지 DB 적재, Django 모델 변경, 마이그레이션, 매출 데이터 변경, 예측 모델 변경을 진행하지 않는다.**
